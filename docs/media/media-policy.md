# Media Policy

Diagrams and screenshots are evidence-bearing product content. Keep editable diagram sources, captions, alt text, references and version history in Git. Use exact product UI only from verified captures and never imply a vendor partnership. Large videos or binary source masters belong in approved media storage, with immutable web renditions referenced by stable asset IDs.

Generated imagery may support editorial atmosphere but may not fabricate architecture, logos, UI, benchmarks or citations. All technical diagrams must be deterministic, reviewable and readable without motion. A future docs site should use Vercel Blob/Image for new web media and provide reduced-motion and static fallbacks.
